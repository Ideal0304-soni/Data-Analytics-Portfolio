# 🍕 Pizza Sales Analytics Dashboard

## 📌 Project Overview

This project analyzes pizza sales data to identify sales trends, customer ordering behavior, and product performance.

## 🎯 Objective

The goal of this project is to help restaurant management make better business decisions using data.

## 🛠 Tools Used

- SQL
- Microsoft Excel
- Power BI
- Power Query
- DAX

## 📊 KPIs

- Total Revenue
- Total Orders
- Average Order Value
- Total Pizzas Sold
- Revenue by Category
- Revenue by Pizza Size

## 📈 Dashboard

The dashboard includes:

- KPI Cards
- Daily Sales Trend
- Monthly Sales Trend
- Top 10 Selling Pizzas
- Sales by Category
- Sales by Pizza Size
- Orders by Hour

## 🔍 Business Insights

- Peak sales occur during evening hours.
- Large pizzas generate the highest revenue.
- Weekend sales outperform weekdays.
- Classic category contributes the highest sales.

## 💡 Recommendations

- Increase inventory during weekends.
- Promote low-selling pizzas.
- Optimize staffing during peak hours.
